为什么填充与描边顺序会产生不同结果？

Canvas中的填充和描边操作是在同一个路径上执行的：

// 先填充后描边
ctx.beginPath();
ctx.rect(50, 50, 200, 100);
ctx.fill(); // 先执行填充
ctx.stroke(); // 后执行描边 - 描边会覆盖在填充之上
// 先描边后填充
ctx.beginPath();
ctx.rect(50, 50, 200, 100);
ctx.stroke(); // 先执行描边
ctx.fill(); // 后执行填充 - 填充会覆盖部分描边

关键点： 描边是以路径为中心向两侧延伸的。当先填充后描边时，描边完全可见；当先描边后填充时，路径内部的描边部分会被填充覆盖。

调整描边宽度可以更清楚地看到这种差异。描边宽度越大，两种顺序产生的视觉效果差异越明显。
